# 13 · 字幕与文字设计

> 新增分册（对应课程多处零散字幕内容 + 平台实践）。原则：**字幕是给"静音刷视频的人"和"听不清的人"看的**——先可读、再风格化；词时只能用实测值，永远不估算。

## 一、先决策：这一条字幕要不要（输入信号 → 决定）

| 信号 | 决定 |
|:---|:---|
| 短视频/竖屏、平台静音率高（信息流默认静音） | **必须上字幕**，且是主视觉元素之一 |
| 口播教程、技术名词多、人名数字多 | 上段落字幕，关键术语/数字可额外强调 |
| 长视频、影院感叙事 | 字幕小而克制，或只给关键句 |
| 音乐/混剪无语音 | 不上对话字幕；标题/歌词字卡另论（走 `10`/`14`） |
| 画面信息已满（包装/数据卡在屏） | 字幕降级或让位——**一屏一个信息焦点**（见 `10` 化繁为简） |

## 二、两种字幕（本质不同的两件事）

| 类型 | 是什么 | 词时来源 | 何时用 |
|:---|:---|:---|:---|
| **段落字幕（segment）** | 一句/一短语一块，随语音进出场 | 语音段起止 | 默认；所有视频的保底 |
| **逐词 kinetic（word-timed）** | 词到即亮（卡拉OK式高亮/弹跳） | **逐词实测时间戳** | 短视频高能段、口播钩子、强调节奏 |

> **词时红线**：逐词字幕只吃**实测**词时间戳（转写模型返回的 `words`）。段落级时间戳不能"匀一下"当词时用；只有 cue 级字幕时，按字符数均分**并在交付说明里注明是近似**——比"编造的精确"诚实。
> 阅读速度地板：**2.5–3.5 词/秒**可读；超 4 词/秒观众跟不上，要么删字要么加时长。

## 三、可读性铁律（顺序检查，逐条过）

1. **字号**：短视频字号 ≈ 帧高的 4–6%（`fontSize` 是帧高分数的引擎里直接填 0.04–0.06）；长视频 2–3%。
2. **对比**：描边（黑 100%、粗 ≈ 字号 25–30%）或底板（半透明暗板 + 圆角）二选一；白字上白底 = 0 分。**最busy的一帧**上检查对比，不是黑场帧上。
3. **安全区**：四周留 ≥5% 边距；字幕带忌触边；下字幕中心对齐放约 70–80% 高度（`offsetY ≈ 0.35` 即下三分之一附近），避开平台 UI（右侧互动栏、底部进度条）。
4. **不遮脸不遮手**：说话人的嘴与手势是信息；实在冲突就移字幕带或给画面让位。
5. **行长**：一行 3–7 词（中文 8–14 字）；长句切两行，断句断在语义处。
6. **一致性**：一个视频一套字幕样式（字体/字号/颜色/描边）；样式切换 = 章节切换才允许。

## 四、四区文字系统（一屏四区，一区一客）

| 区 | 位置 | 放什么 |
|:---|:---|:---|
| 字幕带 | 下 70–80% 高，居中 | 对白/旁白字幕 |
| 标题区 | 上三分之一 | 大标题/章节题 |
| 人名条 | 下三分之一，**靠左锚定** | 人名/职务（见 `11`） |
| 数据卡 | 画面中央 | 数字/图表/重点（走动效合成，见 `10`） |

> 任何时刻**一区一个元素**；两个元素抢一区 = 削掉一个（化繁为简，同 `10`）。

## 五、风格化（在可读性之上的"讲究"）

- **卡拉OK高亮**：当前词高亮色（品牌强调色，≤10% 画面占比原则同 `motion` 设计约定）；高亮切换落在词实测起点上。
- **入场有性格**：字幕块的进出场随节奏（pop/滑入/淡入）；但**连续两句不要同一入场**两次（变化原则同 `05` 景别递进）。
- **换行与节奏**：一行字幕的显示时长盖住整句语音（对齐口播节奏，同 `03` B-roll 五注意第一条）。
- **强调手法**：关键数字/术语用字重（600→900）或强调色，**不用**连续三个感叹号和全大写滥用。
- **字体**：短视频粗无衬线（600+）；别用衬线体做动效字幕（小字号发虚）。

## 六、Agent 输出规范

```
captions = {
  style: {font, fontSize(帧高分数), weight, stroke: {color,width}, plate?:bool, zone:"lower"},
  cues: [ {text, t_in, t_out, words?:[[word, start, end], ...], emphasized?:[idx]} ]
}
```

- 段落字幕省略 `words`；kinetic 必须带且必须实测。
- 交给 editor 落地；黑场红线同全局（字幕盖不住的语音空缺标注交回，不删主轨）。

## 七、给"答疑模式"的速答

- **"字幕要不要加？"** → 短视频基本要；判断标准是"静音刷能不能看懂"。
- **"字幕老是被平台 UI 挡住？"** → 下带放 70–80% 高、四周 5% 安全区，避开右栏互动。
- **"逐词弹跳字幕怎么做？"** → 拿逐词实测时间戳（转写 `words`），没有就退回段落字幕，别编词时。
- **"一句话字幕多长合适？"** → 3–7 词/行，2.5–3.5 词/秒可读；超了删字或分屏。
- **"字幕和标题打架？"** → 四区系统，一区一客；同区冲突削掉次重要的。

## 八、落地说明（交给 editor-* 技能）

- **FUNCUT（`editor-funcut`）**：段落 `captions_add {start,end,text}`；逐词 kinetic `captions_animate`（只吃实测词时）；样式 `title_add`（31 预设，`fontSize` 是帧高分数 0.04 默认 / 0.05–0.06 短视频，`offsetY 0.35`）；字号/描边按上表数值。
- **代码视频（`editor-code-video`）**：FFmpeg `subtitles=` 烧 ASS（`\bord\3c` 描边、`\fn\fs` 字体字号、Karaoke `\k` 标签逐词）；Remotion 按词时驱动 `<Sequence>` + `interpolate` 做高亮（词时作 props 传入）。
- **剪映 / 其他 NLE（`editor-other-nle`）**：剪映"智能字幕"识别 + 花字/文字模板；Premiere 字幕轨；达芬奇字幕轨 + 样式预设。样式数值同上表，按钮路径查对应软件文档。
