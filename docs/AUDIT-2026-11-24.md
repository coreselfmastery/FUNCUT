# Second-pass audit - 2026-11-24

This records the findings from a second review of the tree, the build
configuration and CI. It is a working list, not a release note. Items
already tracked in [KNOWN_ISSUES.md](../KNOWN_ISSUES.md) keep their
numbers there; this file adds the new findings and says what this pass
changed.

## Fixed in this pass

| Finding | Change |
| --- | --- |
| `install-linux.sh` silently fell back to upstream Concat when the fork had no release. | The default fallback is now empty. A missing fork release fails loudly and names `--use-upstream`; that flag is the only way to take upstream's build. |
| The shipping profile uses `panic = "abort"`, so a panic closes the editor before a worker save can finish. | `concat_host::logs::save_on_panic` gives the panic hook a last-chance callback; `Studio::save_now` writes the document synchronously on the panicking thread. Failures are logged, never raised. |
| AUTO EDIT's plan named a curiosity gap and a payoff in the brief but wrote only `hook`/`body`/`cta` sections. | `story_sections` now writes `hook`, `curiosity`, `progression`, `payoff` and `ending`; longform adds `intro`, `rehook` and `cta`. The schema and section-order validator accept them. |
| The `.15` notes said "cut on 23 November" while side-branch work was still landing. | The letter now says first cut 23 November, re-cut 24 November; the README carries the 24 November date. |

## New findings

### Performance and responsiveness

- **N1 - Whole-window redraw on every change.** A comment in
  `src/Cargo.toml` says Skia partial rendering is off, so every dirty
  property redraws the whole window. This is the first thing a `perf`
  capture should confirm on the antiX laptop. Try another Slint
  renderer or reduce the properties that change during a timeline drag.
- **N2 - No 4 GB memory cap in CI.** `scripts/benchmark.py` exists but
  no lane runs it under `prlimit` or a cgroup limit. Add a small-laptop
  lane so a memory regression fails before a user sees it.
- **N3 - AUTO EDIT stage timing is not recorded.** The Whisper step and
  B-roll fetching are the suspected slow parts on 4 GB, but the run does
  not emit per-stage wall times. Add timings to the run record before
  optimizing.

### Reliability and safety

- **N4 - Panic handling still has no crash upload or recovery prompt.**
  This pass saves the project before the abort. A crash report is a
  separate privacy decision; until then, the log file is the only
  evidence and Settings > About is where a user finds it.
- **N5 - Unsafe code is concentrated in `concat-media`.** The tree has
  108 `unsafe {` blocks and 90 `SAFETY` comments. The count is close,
  but the media crate's FFmpeg calls deserve Miri or sanitizer runs, not
  only comments.
- **N6 - `ort` is pinned to a release candidate.** `src/Cargo.toml`
  pins `=2.0.0-rc.13`. The audit environment could not reach crates.io
  to confirm a stable release; keep the pin digest-checked and revisit
  when a stable version exists.
- **N7 - External hosts are hardcoded.** `huggingface.co` appears 19
  times, Pexels 15, Pixabay 8 and archive.org 2. Add bounded timeouts,
  retries and an explicit offline message where the user can act on it.
- **N8 - The translated READMEs still link upstream.** The English
  README and the installer point at `coreselfmastery/FUNCUT`; the
  translated files still carry `jub0t/Concat` issue and discussion
  links. Decide whether that is attribution or a wrong-build trap.

### Process, CI and repository shape

- **N9 - Documentation overlaps.** `AGENT_STATE.md`, `SESSION_HANDOFF.md`,
  `TEST_EVIDENCE.md`, `IMPLEMENTATION_LEDGER.md`,
  `GENEVA_MASTER_LIST.md` and `docs/` audit files repeat counts that have
  already disagreed (100/103/104/114 tools). Keep one source of truth and
  add a CI check that the counts match.
- **N10 - CI is slow.** The `Engine tests and lints` job runs
  `cargo clippy --workspace --all-targets -j 1`; this pass watched it
  exceed 45 minutes on PR 208. The job ceiling is 200 minutes. Split
  clippy from tests or cache the target directory.
- **N11 - Large binaries are tracked.** The two CJK fonts are 3.5 MB and
  2.7 MB, the editor screenshots are ~1.9 MB each, and a sample clip is
  1.4 MB. Move them to Git LFS or release assets if clone weight matters.
- **N12 - No golden AUTO EDIT plan test.** `docs/DETERMINISM.md` says a
  fixed clip can produce a stable plan. A checked-in expected plan would
  turn silent skips into diffs.
- **N13 - The headless smoke path is not separately exercised.** The
  windowed `--smoke` runs in `build-app.yml`; `smoke_headless` exists for
  machines without a display but no lane runs it on every PR.
- **N14 - `unwrap`/`expect` density is high.** The tree has about 4,105
  occurrences, many in tests. Start with `concat-host` and
  `concat-motion`, where a panic would take the window down.
- **N15 - Clippy allowances and ignored tests need review.** There are
  29 `allow(clippy...)` attributes and 15 `#[ignore]` tests. Each one is
  a warning or a test that is no longer running.
- **N16 - Three files dominate the source.** `director_program.rs` is
  about 15k lines, `studio.rs` about 14k and `tools.rs` about 8k.
  Splitting them is a refactor, not a bug fix; do it behind tests.

## What this pass did not do

The target-hardware benchmark, a real AUTO EDIT run, dependency upgrades,
LFS migration, Miri/sanitizer runs and the large-file split need either
the user's laptop or a separate change window. They stay on the list
with the evidence they still need.
