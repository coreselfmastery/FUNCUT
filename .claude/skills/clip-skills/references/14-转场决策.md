# 14 · 转场决策

> 新增分册（整合 `01`/`04`/`05` 中散落的转场内容并系统化）。原则重申：**转场是调味料不是主菜**——默认直切，转场必须"挣来"（earned），不是"装点"。

## 一、第一个决策：要不要转场（大多数答案是"不要"）

```
切点出现 → 这是什么切？
├─ 同场景、同主体、时间连续（口播删气口后的拼接）→ 直切（或叠化遮蔽，见 `03`）
├─ 段落转换/章节切换/情绪转折 → 可以上一个转场（密度地板：段落切换必一个，其余直切优先）
├─ 时间大幅跳跃（回忆/闪进闪出）→ 叠化/闪白类表达时间
├─ 空间跳跃（换场换城市）→ wipe/whip 类表达位移
└─ 强调/冲击（爆点前）→ zoom/glitch 类表达能量
```

> 直切率：一个合格剪辑里**大多数切点是直切**。全片逢切必转 = 业余信号。
> 节奏红线（同 `05`）：切点优先落节拍/重音；转场本身也是一次"切"，**转场中点或落点要对节拍**，不是随便放。

## 二、转场语义表（选型的判断依据）

| 转场家族 | 语义（观众读到什么） | 代表 | 何时用 | 何时忌 |
|:---|:---|:---|:---|:---|
| **叠化/溶解** | 时间流逝、回忆、缓和 | dissolve / blur-dissolve / fade-black / fade-white | 时间跳跃、情绪段落收束 | 高能段（泄气）；连续两个叠化 |
| **擦除（wipe）** | 位移、扫过、新空间 | linear-wipe / shape-wipe / clock-wipe / push / slide | 空间转换、列表推进、综艺感 | 严肃叙事（显廉价）；方向乱 |
| **运动衔接** | 能量延续、镜头间动量传递 | whip-pan / spin / zoom-transition / zoom-blur-transition | 前后镜头都在动、节奏高峰 | 静→静镜头间（无动量可接） |
| **风格特效** | 时代/媒介质感、故障感 | glitch / film-burn / light-leak / VHS 类 | 科技/复古题材的风格系统 | 题材无关时乱入（"特效是调味料"） |
| **光圈/形状** | 聚焦、开场、结束 | iris（光圈开合） | 开场揭示、结尾收束 | 中段高频使用 |
| **3D/立体** | 翻页、块面感 | cube / rgb-split | 综艺、快节奏包装 | 采访、纪录片 |

选型流程：**先定语义（这一切要表达什么）→ 再查表选家族 → 家族内选最克制的那个**。选不出语义 = 直切。

## 三、时长与节奏（数值依据）

| 类型 | 建议时长 | 依据 |
|:---|:---|:---|
| 快速动量转场（whip/zoom） | 0.2–0.4 s | 越快越"顺"，拖长变"假" |
| 标准叠化/溶解 | 0.5–1.0 s | 盖住两镜头衔接处的生硬即可 |
| 风格特效（glitch/film-burn） | 0.3–0.8 s | 长了抢戏 |
| 段落大转换（fade-black） | 1.0–1.5 s | 给观众"翻页"的呼吸 |

> 所有转场**配一个音效**（whoosh/impact 类峰值落在转场中点，音效选择见 `04`）——无声的转场只完成了一半。

## 四、与"切型"的关系（别混淆两套词）

- **切型（cut type）**是剪辑语法：直切、J/L-cut、匹配剪辑、跳切、动作切（见 `05` §五）——它们**不用转场特效**。
- **转场（transition）**是特效层的包装：叠化/擦除/whip……
- 关系：先选切型，切型表达不了的（时间/空间/能量跳跃）才上转场。**J/L-cut 优先于叠化**处理声音衔接（声音先行/延续比画面溶解更高级，见 `04`）。

## 五、Agent 输出规范

```
transition = { clip:"进场片段", id:"dissolve", duration:0.6, sfx:{id:"whoosh-01", peakAt:"转场中点"} }
```

- 落点写在**进场片段**上（多数 NLE 的转场属性属于后一个片段；FUNCUT 是 `transitionIn`，打在进场片段）。
- 相邻两片段须**同轨无缝**——移动/有缝的切点上放转场会静默失效（落地细节见 editor 技能）。
- 密度自检：数一遍成片——段落切换各一个 + 全片不超过"每 15 秒一个"（高能长视频）；超标删到只剩有语义的。

## 六、给"答疑模式"的速答

- **"什么时候该用转场？"** → 段落/时间/空间/能量四处跳跃之一，其余直切；说不清为什么用就别用。
- **"转场多久合适？"** → 快动量 0.2–0.4s、叠化 0.5–1s、段落 fade 1–1.5s；超过 1.5s 都在抢戏。
- **"为什么我的转场看起来很土？"** → 通常是滥用（逢切必转）+ 无语义（随机选型）+ 没配音效。
- **"两镜头怎么接更顺？"** → 先想切型（J/L、匹配剪辑、动作切），转场是最后手段。

## 七、落地说明（交给 editor-* 技能）

- **FUNCUT（`editor-funcut`）**：`clip_update {patch:{transitionIn:{id,duration}}}` 打在**进场片段**（同轨相邻！），22 个包用 `effects_list {kind:"transition"}` 实查：dissolve、blur-dissolve、fade-black、fade-white、whip-pan、push、slide、spin、swirl、cube、iris、clock-wipe、linear-wipe、shape-wipe、zoom-transition、zoom-blur-transition、glitch-transition、glitch-warp、film-burn、light-leak-flash、light-leak-transition、rgb-split-wipe。**不要**用 `effect_layer_add` 放转场（层带不动双输入，渲染为空）。
- **代码视频（`editor-code-video`）**：FFmpeg `xfade=transition=<name>:duration=D:offset=第一段时长-D`（两路须同分辨率/SAR/帧率，offset 常算错——见其 cookbook ⑧）；音频配 `acrossfade`；Remotion 用 `interpolate` 驱动透明度/位移自制转场。
- **剪映 / 其他 NLE（`editor-other-nle`）**：剪映转场面板按家族分类（叠化/运镜/幻灯片/特效），时长用上表数值；Premiere 在"效果>视频过渡"；达芬奇 Effects 库拖到切点。参数数值同上表，按钮路径查软件文档。
