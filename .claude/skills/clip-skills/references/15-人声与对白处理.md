# 15 · 人声与对白处理

> 新增分册（整合 `02`/`04` 中人声相关内容并补齐缺口）。原则：**人声是信息主干，一切处理服务"清晰 + 自然"**；链路固定为 清洗 → 修复 → 摆位 → 响度，顺序不可乱（在坏底上做美化 = 白做）。

## 一、链路总览（决策顺序）

```
拿到的语音 → 检查（听/测） → 降噪 → EQ → 压缩/ leveling → （除齿音） → 摆位/duck → 响度达标
```

每一步都**先测后动、小步走**：处理过度的标志是"水下感"、金属感、呼吸声消失——宁可轻不可重。

## 二、清洗与修复（情况 → 依据 → 决定）

| 问题特征 | 判断依据 | 决定 | 度 |
|:---|:---|:---|:---|
| 底噪/嗡声（持续宽带噪声） | 录音环境差、增益高 | 降噪（谱减/FFT 类） | **轻**：强度从低往高试，出现"水纹感"就回退一档 |
| 喷麦（"噗"爆音，波形顶到削波） | 嘴离麦太近、无防喷罩 | 低切/高通先滤（80–100Hz 以下）；已录死的做衰减修复 | 高通斜率 12dB/oct 起 |
| 齿音刺耳（"呲呲"） | 女声/年轻声常见、麦克风亮 | 除齿音（de-esser） | 只压 5–8kHz 频段，过重变"漏气" |
| 房间混响重（拖尾浑） | 空房硬墙录音 | 事后难救：轻度减混响或**重录** | 混响重的重录 > 一切插件 |
| 单声道素材 | 波形单边/兼容性差 | 修双声道复制 | 无损操作，做 |
| 爆音/破音（削波失真） | 电平超 0dBFS | 无法完全修复：衰减 + 削波修复；能重录就重录 | — |

> 红线：**降噪与除齿音宁欠勿过**——损失的信息补不回来；混响重的直接建议重录，别硬救。

## 三、EQ 与压缩（塑造，不是整容）

- **EQ 三段法（口播通用起点）**：
  1. **高通 80–100Hz**（去隆隆与喷麦余量）；
  2. **中频按需**：鼻音重 200–400Hz 轻切；"盒子感" 400–800Hz 轻切；想要"存在感" 2–4kHz 轻**提升**（过强刺耳）；
  3. **气声 10kHz+ 轻提升**（可选，增"空气感"；底噪大时跳过）。
- **压缩/电平统一**：口播 Ratio 2:1–4:1、慢启动（attack 10–30ms）；目的是**句句等响**，不是压"死"动态。
- 响度差 >3dB 的多段素材先各自归一，再统一压；后期补录句要**对齐原口播响度与音色**（同麦同距最好；EQ 匹配次之）。

## 四、气口与呼吸（与 `02` 联动）

- 气口三规则（保留/扩充/叠化垫音）见 `02` §三——本册只补音频侧：
- 呼吸声**不删光**：全删 = 机器人感；轻减 6–10dB 保留存在感。
- 切点在波形**过零点**附近最干净（落地由 editor 按帧对齐）。
- 后期补录：防喷麦、同位对齐、响度匹配（见上）。

## 五、摆位与让位（与 `04` 联动）

- **BGM duck**：人声出现时 BGM 压低——口播标准 −12dB 档（紧 −9 / 松 −15，BGM 才气与段落见 `04`）；duck 的起落要**随人声首尾**（侧链或手动关键帧），不是一刀切平。
- **音效不抢频**：人声在场时，音效避开 1–4kHz 人声核心区（选低频 impact / 高频 sparkle 类）。
- **J/L-cut** 的声音进出（环境声提前 2–3 秒渐入）见 `04` §三，同样适用于人声段落的进出。

## 六、响度达标（数值表 + 实测红线）

| 目标平台 | 集成响度（LUFS） | 真峰（dBTP） |
|:---|:---|:---|
| 短视频（抖音/TikTok/Reels/Shorts） | **−14** | ≤ −1 |
| YouTube 通用 | −14 | ≤ −1 |
| 播客/纯语音 | −16 | ≤ −1.5 |
| 广播（EBU R128） | −23 | ≤ −1 |

> **实测红线**：响度是**测出来的不是计划出来的**——导出后必须用响度计（EBU R128 集成）量，不达标回修 `clip_audio_levels_db` 类工具再量。"我觉得够响"不算数。

## 七、配音/旁白的生成与修复（生成层）

- 缺旁白：TTS 生成（选 delivery/语气；长稿**分段生成**、按情绪段各配语气再拼接，单语气到底 = "廉价感"主因之一）；生成后同样走 §三/§六 链路。
- 长静音/换气过长：`vad` 类预过滤或静音检测后裁（见 `02`）。
- 语速：2.5–3.5 词/秒（≈ 中文 4–6 字/秒）可读上限同 `13` 阅读速度地板。

## 八、Agent 输出规范

```
voice_chain = {
  clean: {denoise: {strength:"low|med"}, highpass: "100Hz"},
  shape:  {eq: ["hp 100", "cut 300Hz -2dB", "shelf 3kHz +1.5dB"], deess: "5-8kHz light"},
  level:  {compressor: "3:1 slow attack", target_lufs: -14},
  place:  {duck: {bgm: -12, tight: -9, relaxed: -15}}
}
```

交给 editor 落地；参数是**起点不是圣旨**，落地后必须复听（或复测响度）。

## 九、给"答疑模式"的速答

- **"人声闷/不清楚？"** → 链路走一遍：先降噪（轻）→ 高通 100Hz → 2–4kHz 轻提升 → 句间等响；别先加混响。
- **"录音有嗡嗡底噪？"** → 降噪从轻往高试，出现水纹感回退；底噪太重考虑重录——降噪救不了差的源头。
- **"BGM 总盖人声？"** → duck 没做或不够深：人声下压 BGM 12dB 档，起落跟人声首尾。
- **"补录的句子和原来不搭？"** → 响度与音色没对齐：同麦同距重录，或 EQ+响度匹配后再混。
- **"导出后声音忽大忽小？"** → 没做响度达标：导出后实测 LUFS（短视频 −14），不达标回修。

## 十、落地说明（交给 editor-* 技能）

- **FUNCUT（`editor-funcut`）**：音频包 `effects_list {kind:"audio"}` 实查——`concat.denoise`（降噪，强度轻→重）、`concat.enhance-voice`（人声增强）、`concat.bass`/`concat.treble`（EQ）、`concat.pitch`、`concat.loudness`（响度）；响度实测 `measure_loudness {path, targetLufs}`（−14 短视频 / −23 广播）；duck 用 `clip_audio_levels_db {keyframes}`（dB 值，不是线性乘数）；补录/TTS 用 `tts_generate`（delivery/speed/pauses 控语气）。
- **代码视频（`editor-code-video`）**：FFmpeg `afftdn`（降噪）、`highpass=f=100`、`equalizer=`/`bass=`/`treble=`、`acompressor`（压缩）、`deesser`、响度两遍法 `loudnorm`（其 cookbook ⑥；目标 I=−16 语音 / −14 短视频平台 / −23 广播）。
- **剪映 / 其他 NLE（`editor-other-nle`）**：剪映"音频>降噪"开关 + 人声增强；Premiere Essential Sound"语音"面板；达芬奇 Fairlight 页专业链。数值同上表，按钮路径查软件文档。
